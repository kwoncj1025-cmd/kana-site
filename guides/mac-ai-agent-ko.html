맥에서 쓰는 AI 에이전트, 무엇을 맡기고 무엇을 확인할까

2026년 11월 27일 · YOOANPAPA

채팅형, 화면 조작형, 바탕화면 비서형. 맥에서 쓰는 AI 에이전트의 세 종류와, 메일·결제를 맡기기 전에 꼭 볼 한 가지.

요즘 「AI 에이전트」라고 불리는 맥 앱은 꽤 달라요. 어디에 있고 어떻게 일하는지로 나누면 고르기 쉬워요.

맥 AI 에이전트, 세 종류

  1. 채팅형. 창을 열고 물어보면 답하고, 에이전트 모드에서는 웹을 찾아보거나 몇 단계 일을 해 줘요. 질문·조사에 좋지만, 내가 창을 열어야 움직여요.
  2. 화면 조작형. 화면을 보고 마우스·키보드를 대신 움직여요. 거의 모든 앱을 다룰 수 있지만 화면을 차지하고, 대개 그동안 손을 놓고 기다려야 해요.
  3. 바탕화면 비서형. 작은 캐릭터나 위젯이 바탕화면에 늘 있어요. 상태만 보여 주는 것도 있고, 심부름을 직접 하는 것도 있어요.

가장 중요한 한 가지: 묻지 않고 무엇을 하나

  • 일정 보기, 페이지 요약처럼 읽는 일은 위험이 낮아요.
  • 메일 보내기, 게시, 예약, 결제, 삭제는 되돌릴 수 없어요.

좋은 에이전트는 나가는 내용(받는 사람·금액·첨부)을 그대로 보여 주고 기다려요. 또 메일이나 웹 페이지 속 글을 명령이 아니라 자료로 다뤄야 해요. 그래야 웹 페이지에 숨은 한 줄이 「파일을 어디로 보내」 같은 지시를 해도 따르지 않아요.

그 밖에 볼 것

  • 누구의 AI를 쓰나. 구독이 묶여 있는지, 내 API 키로 쓰는지.
  • 자체 서버가 있나. 없으면 부탁이 내 맥에서 AI 회사로 바로 가요.
  • 값. 매달 내는지, 한 번 사면 끝인지.
  • 맥 조건. Apple 실리콘 전용인지, macOS 몇 이상인지.

카나는

카나는 심부름을 하는 바탕화면 비서형 AI 에이전트예요. 손으로 그린 캐릭터가 바탕화면에 서 있고, 말풍선으로 일을 맡기면 Claude Code(내 Anthropic API 키 또는 Claude Code 로그인)로 메일·일정·파일·웹 일을 해 두고 한 줄로 보고해요. 읽는 건 묻지 않고, 보내기·게시·예약·결제·삭제는 승인 카드에서 꾹 눌러야 나가요. 카나에는 자체 서버가 없어요. macOS 13 이상, Apple 실리콘, 한 번 구매.
