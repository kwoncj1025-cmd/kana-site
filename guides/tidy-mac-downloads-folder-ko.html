맥 다운로드 폴더 한 번에 정리하기

2026년 11월 28일 · YOOANPAPA

설치 파일·스크린샷·영수증이 수백 개 쌓인 다운로드 폴더, 약 5초 만에 종류별로 나누는 법. 먼저 안을 보고, 마음에 안 들면 되돌려요.

다운로드 폴더는 파일이 잊히는 곳이에요. 이미 깐 설치 파일, 스크린샷, 나중에 정리하려던 영수증. 손으로 하면 30분은 걸려서 결국 안 하게 돼요.

보통 쓰는 방법

  • Finder 에서 손으로. 종류별 정렬 → 폴더 만들기 → 끌기. 되긴 하지만 느리고 중간에 멈추게 돼요.
  • 스택·스마트 폴더. 어지러움을 가려 줄 뿐, 옮겨 주지는 않아요.
  • 규칙 앱. 한 번 맞춰 두면 좋지만 규칙부터 써야 해요.

카나와 함께: 그냥 말하기

  1. 「다운로드 정리해 줘」라고 말해요.
  2. 카나가 파일 이름과 종류를 보고 쪽지 한 장에 안을 보여 줘요. 어느 묶음이 어느 폴더로, 몇 개씩 가는지. 지우는 건 없어요.
  3. 꾹 눌러 OK 하면 한 번에 옮겨요.
  4. 마음이 바뀌면 「방금 정리한 거 되돌려 줘」. 전부 제자리로 가요.

실제 숫자

파일 142개(스크린샷·영수증·회의록·설치 파일·압축 파일 등)가 든 시험용 다운로드 폴더에서, 카나는 스크린샷·영수증·청구서·회의·설치 파일 같은 13곳으로 나눴어요. 2026년 11월 28일 출시판 실측: 첫 쪽지 약 1~3초, 쪽지 1장, 끝까지 약 5초. 되돌리기로 142개 모두 제자리.

알아 두면 좋은 것

  • 어디 둘지 모르는 파일은 그대로 두고 말해 줘요.
  • 오늘 받은 파일은 새것으로 보고 건드리지 않아요.
  • 처음 설정할 때 허락한 폴더 안에서만 일해요.

귀찮은 맥 일은 말로 맡기세요, 카나
