카나 vs OpenClaw 비교

2026년 11월 28일 · YOOANPAPA

OpenClaw 는 아주 인기 있는 오픈소스 개인 에이전트, 카나는 서명된 맥 앱이에요. 각자 잘하는 것을 출처와 함께, 누구에게 무엇이 맞는지 정리했어요.

OpenClaw(옛 이름 Clawdbot)는 GitHub 별이 약 39만 5천 개인 오픈소스 개인 에이전트이고, 커뮤니티도 커요. 카나는 작은 유료 맥 앱이에요. 「귀찮은 일 좀 맡아 줘」라는 같은 바람을 아주 다른 방식으로 풀어요. 출처는 2026년 11월 28일에 확인했어요.

한눈에

카나OpenClaw
무엇서명·공증된 맥 앱, 바탕화면 캐릭터직접 설치해 돌리는 오픈소스 에이전트(MIT 라이선스)
설치DMG 열고 응용 프로그램으로 끌기, Claude Code 로그인내 컴퓨터에 직접 설치·설정·운영
말 거는 곳맥 바탕화면 말풍선Discord·iMessage·Slack·Teams·Telegram·WhatsApp 「외 20곳 넘게」
AI 모델이 맥의 Claude Code(Claude Pro·Max 구독이나 API 키)원하는 모델·키
스스로 깨어나기맥이 깨어 있을 때 아침 브리핑·메일 지켜보기, 바뀐 게 없으면 조용기본 30분마다 하트비트, HEARTBEAT.md 확인 목록대로
행동 실행보내기·결제·예약·삭제는 매번 카드에서 멈춤「샌드박스를 설정하지 않으면 메인 세션의 도구는 호스트에서 실행」
추가 기능내장 스킬만, 장터 없음스킬 장터(ClawHub)
값한 번 19달러무료(모델 사용료·기기 값은 따로)

출처: OpenClaw README, 하트비트 문서

OpenClaw 가 앞선 곳

  • 어디서든 말 걸기. 「이미 쓰는 채널에서 만난다」가 핵심이에요(README). 폰으로 문자하면 내 컴퓨터가 일해요. 너무 인기라 Kaspersky 는 「미국 몇몇 매장에서 맥 미니 품귀를 일으켰다」고 썼어요(Kaspersky).
  • 자유. 오픈소스라 모델을 마음대로 고르고, 코드를 다 읽고 고칠 수 있어요.
  • 검증된 하트비트. 기본 30분마다 깨어나 확인 목록대로 움직여요(문서). 한 레딧 사용자는 「크론은 정말 믿을 수 있다」고 했어요(Kilo 의 레딧 모음).
  • 무료. 라이선스 값이 없어요.

카나가 앞선 곳

  • 설치에 주말을 안 써요. 서명된 DMG 하나예요. 포트·Docker·터미널이 필요 없어요. Kilo 가 모은 레딧 글에는 「기대대로 돌지 않아 포기했다」, 「업데이트마다 버그가 늘었다」는 말이 있어요(Kilo).
  • 다칠 길이 적어요. 2026년 초 Kaspersky 는 일주일쯤 사이 올라온 악성 플러그인 230개 넘게, 인증 없이 인터넷에서 열리는 OpenClaw 설치본 천 개 가까이를 찾았어요(Kaspersky 2026-02-10). 카나는 네트워크 포트를 열지 않고, 남이 만든 스킬 장터가 없고, 맥 밖으로 나가는 일은 카드에서 멈춰요.
  • 비용이 예측돼요. 한 레딧 사용자는 하루 평균 131달러, 모두 5천 달러 가까이 썼다고 했어요(Kilo). 카나는 한 번 19달러에 내 Claude 구독을 쓰고, 바뀐 게 없으면 조용히 있어요.
  • 맥 잔일이 빨라요. 2026년 11월 28일 출시판 실측: 간단한 질문 약 1.5~2.5초, 다운로드 파일 142개 정리 약 5초(쪽지 1장).
  • 얼굴이 있어요. 손그림 캐릭터가 바탕화면에서 일하는 중·다 했어요를 보여 줘요.

카나가 아직 못 하는 것

  • 메신저·폰으로 말 걸기는 아직 없어요. OpenClaw 의 가장 큰 장점이에요.
  • 맥이 깨어 있을 때만 일해요.
  • Claude 만, 맥만(Apple 실리콘, macOS 13 이상) 돼요.
  • 오픈소스가 아니에요.

무엇을 고를까

만지는 걸 좋아하고, 어디서든 문자로 시키고 싶고, 직접 띄운 환경의 보안을 챙길 수 있다면 OpenClaw 가 좋아요. 열자마자 되고, 맥 바탕화면에 있고, 꾹 누르기 전엔 보내지도 결제하지도 않는 비서를 원하면 카나를 고르세요.

자주 묻는 것

카나는 OpenClaw 로 만들었나요?
아니요. 카나는 따로 만든 네이티브 맥 앱이에요. 이 맥에서 도는 Claude Code로 생각하고, OpenClaw 코드를 쓰지 않아요.
OpenClaw 처럼 폰으로 카나에게 문자할 수 있나요?
아직은 안 돼요. 맥 바탕화면의 말풍선으로 말해요.
카나가 OpenClaw 보다 안전한가요?
만든 방식이 달라요. 카나는 네트워크 포트를 열지 않고, 남이 만든 스킬 장터가 없고, 보내기·결제·예약·삭제 전에 매번 물어요. OpenClaw 도 안전하게 설정할 수 있지만, 보안은 어떻게 띄우고 설정하느냐에 달려 있어요.
어느 쪽이 더 싸요?
OpenClaw 는 무료지만 모델 사용료와 기기 값은 따로 들어요. 카나는 한 번 19달러이고, 내 Claude Pro·Max 구독이나 API 키를 써요.

귀찮은 맥 일은 말로 맡기세요, 카나
